# 이미지 이용 주의사항

수집 이미지 중 저작권은 없지만 굿즈 판매 등 다른 용도에 제한이 있는 작품을 기록한다.

## Harper's Magazine, Christmas

| 항목 | 내용 |
|---|---|
| 작가 | Harvey Ellis |
| 제작 연도 | 1898 |
| 재료 | 컬러 석판화 |
| 소장처 | 메트로폴리탄 미술관 |
| 원본 페이지 | https://www.metmuseum.org/art/collection/search/339102 |
| 권리 상태 | 퍼블릭 도메인(메트로폴리탄 Open Access, CC0). 2026-10-23 미술관 공식 API에서 확인 |

### 허용

- 아카이브 사이트에 수집 게시물로 게시
- 이미지 다운로드와 재가공

### 주의

- 포스터에 현재 발행 중인 잡지 이름 "Harper's"가 크게 들어가 있다. 그림의 저작권과 별개로 이 이름은 상표로 보호될 수 있다.
- "Harper's" 글자가 보이는 상태로 굿즈를 만들어 판매하지 않는다.
- 굿즈나 커스텀 작품으로 만들 때는 잡지 이름을 지우고 그림 요소만 사용한다.
